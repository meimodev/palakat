# KartuUsulanAI

Kartu untuk usulan dari AI yang belum menjadi nilai apa pun sampai Bendahara memakainya.

Flutter: `Card` + `DottedBorder` (paket).

**Pemakai memberi:** isi usulan, tingkat keyakinan, dan tiga tindakan: Pakai, Ubah, Abaikan.

- Garis titik-titik `laut` dan huruf miring `lautTua` hanya milik AI: tidak pernah tampak seperti draf atau nilai yang sudah dibukukan.
- Bila AI kurang yakin, tulis “AI kurang yakin, mohon dicek”.
