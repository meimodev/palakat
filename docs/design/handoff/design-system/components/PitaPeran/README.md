# PitaPeran

Pita yang menyebut peran pengguna atau keadaan yang mengunci layar.

Flutter: `MaterialBanner`.

**Pemakai memberi:** satu kalimat pendek.

- Garis penuh `tinta` untuk peran (Akses terbatas: Peruntukan Diakonia).
- Bidang `tinta` untuk keadaan yang mengunci (Belum ada Bendahara aktif).
- Putus-putus untuk yang belum pasti (Sementara).
