# BatangPembagian

Batang yang memperlihatkan berapa bagian dari satu jumlah yang sudah dibagi dan berapa sisanya.

Flutter: `Row` + `Flexible` + `AnimatedContainer`.

**Pemakai memberi:** jumlah keseluruhan dan bagian-bagiannya. Sisa dihitung, tidak diketik.

- Bagian yang belum terisi tetap putus-putus `putus`.
- Sisa yang belum dibagi ditulis dengan `bata`.
- Dipakai untuk saldo awal, pembagian Mata Anggaran dan sisa kasus.
