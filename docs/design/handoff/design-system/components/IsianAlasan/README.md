# IsianAlasan

Isian teks dua baris untuk alasan yang wajib sebelum tindakan tertentu.

Flutter: `TextField` (maxLines 2).

**Pemakai memberi:** contoh alasan sebagai petunjuk dan tombol tindakan yang dijaganya.

- Wajib untuk Batalkan, Pindah tanggal, pembalikan, pengecualian dan Bebaskan.
- Tombolnya nonaktif sampai alasan terisi.
