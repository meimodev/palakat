# LembarBawah

Lembar yang naik dari bawah layar ponsel untuk pilihan atau isian singkat.

Flutter: `showModalBottomSheet`. Sudut atas `radius-lembar`, naik dalam 280 ms.

**Pemakai memberi:** judul (`judulLayar`) dan isi.

- Di web, isi yang sama tampil sebagai panel di samping, bukan lembar yang menutupi halaman.
