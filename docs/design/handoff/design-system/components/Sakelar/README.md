# Sakelar

Sakelar hidup atau mati untuk pengaturan.

Flutter: `Switch`.

**Pemakai memberi:** label dan kalimat yang menyebut mulai bulan apa perubahan berlaku.

- Hidup: bidang `tinta`. Mati: garis `tinta` di atas `permukaan`.
- Selalu ditemani kalimat yang menyebut mulai bulan apa perubahan berlaku.
