# StatusSimpan

Teks dan pita yang selalu jujur tentang apakah isian sudah tersimpan.

Flutter: `Text` + `MaterialBanner`.

**Pemakai memberi:** keadaan simpan saat ini.

- Tersimpan dengan `laut`; Belum tersimpan dan Mencoba menyimpan lagi… dengan `tinta3`.
- Gagal disimpan: latar `bataLembut`, garis `bata`, dengan tombol Coba lagi. Isian tetap ada di layar.
- Coba lagi tidak pernah membuat transaksi ganda atau No. Bukti kedua.
- Bila data diubah orang lain, minta muat versi terbaru sebelum melanjutkan.
