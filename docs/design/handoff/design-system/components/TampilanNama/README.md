# TampilanNama

Pilihan anggota tentang bagaimana namanya tampil di publikasi, dengan pratinjau.

Flutter: `RadioListTile` + `Card`.

**Pemakai memberi:** pilihan pribadi anggota, bawaan keluarga, dan contoh kalimat untuk pratinjau.

- Tujuh bentuk: Nama lengkap, Nama keluarga, Keluarga + Kolom, Kolom, BIPRA, BIPRA + Kolom, Tanpa nama.
- Pilihan anggota wajib diikuti di Warta Jemaat dan publikasi lain; format dan penyunting tidak dapat melemahkannya.
- Pilihan pribadi yang lebih tertutup mengalahkan bawaan keluarga.
- Beri peringatan “Masih mudah dikenali” bila bentuk yang dipilih masih menunjuk satu orang.
- Hanya Sekretaris Jemaat yang menampilkan nama sebagai pengecualian, dengan alasan dan catatan di Riwayat.
- Perubahan berlaku untuk publikasi berikutnya; edisi lama tidak berubah.
