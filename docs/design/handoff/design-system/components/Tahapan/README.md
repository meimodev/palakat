# Tahapan

Deret chip bernomor yang menunjukkan langkah mana yang sudah dilewati.

Flutter: `Row` berisi `Chip`. Tinggi 30, sudut `radius-chip`, teks `keterangan` tebal 700.

**Pemakai memberi:** daftar langkah berurutan dan langkah yang sedang berjalan.

- Yang sudah dilewati terisi penuh `tinta`; yang belum memakai garis putus-putus `putus`.
- Dipakai untuk versi Mata Anggaran, impor dan pemeriksa kedua.
