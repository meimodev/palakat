# RangkaianKoreksi

Tiga kartu bersambung: transaksi yang dibalik, pembalikannya, dan transaksi koreksi.

Flutter: `Column` + `Card` + `VerticalDivider`.

**Pemakai memberi:** No. Bukti ketiga transaksi dan statusnya.

- Garis tegak 2 `tinta` menyatakan “terkait dengan”.
- Transaksi yang dibalik tetap terlihat dengan lencana Dibalik; tidak ada yang dihapus.
- Dipakai juga untuk pengembalian dan serah terima Bendahara.
