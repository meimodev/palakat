# ChipPilihan

Chip untuk memilih satu dari sedikit pilihan yang semuanya terlihat.

Flutter: `ChoiceChip`. Tinggi `size-sentuhMin`, sudut `radius-chip`.

**Pemakai memberi:** label isian dan daftar pilihan.

- Terpilih: bidang `tinta`, teks `permukaan`. Belum terpilih: garis `garisTegas` di atas `permukaan`.
- Kas/Bank, peruntukan, Lingkup dan Mata Anggaran selalu empat isian terpisah. Tidak ada yang ditebak dari yang lain.
