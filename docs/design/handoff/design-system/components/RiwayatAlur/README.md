# RiwayatAlur

Daftar singkat tindakan yang baru dijalankan, terbaru di atas.

Flutter: `ListView` di dalam `Card`, tanpa aksi.

**Pemakai memberi:** baris riwayat dari catatan yang sama dengan tab Riwayat pada data itu.

- Setiap baris memuat tanggal, apa yang dilakukan, siapa, dan jabatan yang dipakai.
- Alasan yang diketik ikut tercatat apa adanya.
- Tindakan yang dijalankan Operator untuk jabatan kosong menyebutnya di baris itu.
- Riwayat tidak dapat diubah atau dihapus dari sini.
