# PenghitungPecahan

Baris hitung kas: pecahan, tombol kurang dan tambah, jumlah lembar, dan hasil kalinya.

Flutter: `IconButton` + `Text`.

**Pemakai memberi:** nilai pecahan dan jumlah lembar. Hasil kali dihitung.

- Tombol tambah lebih gelap daripada tombol kurang, karena menghitung hampir selalu menambah.
- Kedua tombol berukuran `size-sentuhMin`.
- Angka memakai keluarga mono supaya digit sejajar.
