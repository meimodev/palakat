# Penolakan

Kalimat penolakan yang menyebut sebabnya dan menawarkan langkah yang memang tersedia.

Flutter: `Text` + `FilledButton` atau `OutlinedButton`.

**Pemakai memberi:** tindakan yang ditolak, sebabnya, dan jalan keluar yang tersedia.

- Bentuk kalimat: “Tidak dapat dilakukan: ‹tindakan›.” dengan `bata`, lalu sebabnya dengan `tinta`.
- Setiap penolakan menawarkan langkah yang tersedia (Pindah tanggal, Batalkan).
- Tidak pernah menyebut membuka bulan lagi: bulan yang sudah ditutup tidak dibuka.
