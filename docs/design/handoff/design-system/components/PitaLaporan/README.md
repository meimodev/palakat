# PitaLaporan

Pita di atas laporan yang menyebut apakah laporan itu sementara atau resmi.

Flutter: `MaterialBanner`.

**Pemakai memberi:** jenis laporan; untuk laporan resmi juga waktu tutup buku dan ID salinan.

- Laporan sementara: garis putus-putus, “Bukan laporan resmi. Angka masih dapat berubah.”
- Laporan resmi: bidang `tinta`, teks `permukaan`, pendamping `diTinta2`, ID dengan keluarga mono.
- Salinan terbatas berjudul TERBATAS.
