# ButirPerhatian

Tiga tingkat perhatian: Hambatan, Perlu tindakan, dan Untuk diketahui.

Flutter: `Card` + `ListTile`.

**Pemakai memberi:** tingkat, judul, satu baris keterangan, dan untuk Hambatan tombol ke perbaikannya.

- Hambatan: garis 1,5 `bata`, label “HAMBATAN”, selalu membawa tombol ke perbaikannya.
- Perlu tindakan: kartu biasa dengan panah.
- Untuk diketahui tampil polos, tanpa bingkai dan tanpa warna peringatan.
- `bata` tidak dipakai untuk apa pun selain hambatan dan kegagalan.
