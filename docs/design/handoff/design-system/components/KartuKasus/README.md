# KartuKasus

Kartu satu kasus Uang Muka, Titipan atau Penggantian biaya dengan sisa yang masih berjalan.

Flutter: `Card` + `LinearProgressIndicator`.

**Pemakai memberi:** nama kasus, pihak, jumlah awal, jumlah yang sudah dipertanggungjawabkan, dan jatuh tempo.

- Sisa selalu dihitung, tidak pernah diketik.
- Bagian yang belum dipertanggungjawabkan tetap putus-putus.
- Lewat jatuh tempo ditebalkan, tanpa warna hambatan.
