# KartuPersetujuan

Kartu yang mencatat persetujuan yang terjadi di luar aplikasi.

Flutter: `Card`.

**Pemakai memberi:** pemberi persetujuan dan jabatannya, tanggal, cara (misalnya notulen rapat), serta siapa yang mencatat.

- Belum dicatat: garis putus-putus dengan tombol “Catat persetujuan”.
- Sudah dicatat: garis penuh, dengan baris “Dicatat oleh …. Pernyataan Bendahara, bukan persetujuan di dalam aplikasi.”
- Tidak diperlukan ditulis polos dengan aturannya.
- Tidak ada tombol “Approve” dan tidak ada tanda tangan tiruan.
