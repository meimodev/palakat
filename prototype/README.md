# Palakat prototype

A clickable Flutter prototype of the Palakat design. It has all 199 boards of the canvas (`docs/design/handoff/canvas/canvas.json`), each as its own route `/<Stem>`, built from mock data with no backend. The prototype follows the board sources (`docs/design/handoff/canvas/boards/<Stem>.dc.html`) and the specs in `docs/build/screens/`. It was built and verified against them as described in `docs/build/README.md`, and every difference found is recorded in `docs/build/review-log.md`.

## Run

Flutter 3.47.8 through [fvm](https://fvm.app). From this folder:

```bash
fvm flutter pub get
fvm flutter run -d chrome
```

The launcher at `/` lists every board by canvas page and by role journey. `/<Stem>` opens a board directly, for example `/#/Main` or `/#/WebBeranda`. The floating **Keadaan** panel switches the board's tweaks and the global switches: vacant post (`jabatanKosong`), theme, reduce motion and device frame. It also holds the prototype-only devices. Phone boards render in a device frame on wide windows. Laptop and tablet boards are fluid pages, and A4 boards are fixed pages. `/_komponen` is the component gallery.

## Check

| What | Command |
| --- | --- |
| Analyze | `fvm flutter analyze` |
| All tests | `fvm flutter test` |
| One board | `fvm flutter test test/routes_test.dart --plain-name '/Main '` (also works for `rules_test.dart`) |
| Release build | `fvm flutter build web --release`, output in `build/web/`, works as static files |
| Compare with the board | `tool/compare.sh Main [tweak=value] [--click TEXT] [--width W --height H]` writes `build/shots/pair/<name>.png`, board left and app right (needs Google Chrome; see `tool/SHOTS.md`) |

The tests:

| Test | What it checks |
| --- | --- |
| `registry_test` | The 199 boards against the canvas and the manifest |
| `routes_test` | Every board at its frame size and each tweak option, and laptop boards at 1280, 860 and 390 wide |
| `links_test` | Every link the board sources have (1282) |
| `deep_link_test` | Every child route opened by URL |
| `rules_test` | The widget sweeps of `docs/build/rules-checklist.md` |
| Other files | Components, motion, formatters, the shells and the device frame |

## Layout

| Path | What it holds |
| --- | --- |
| `lib/boards.dart`, `lib/router.dart` | The board registry and the routes, generated by `tool/gen_boards.py`. Do not edit or `dart format` them; re-run the generator |
| `lib/screens/<pageId>/` | One screen file per board (`<snake_stem>.dart`), plus its part files |
| `lib/widgets/` | The design-system components (`docs/build/components.md`) |
| `lib/shell/` | Device frame, page scaffolds, side nav, tab bar, launcher, Keadaan panel, `Tautan` links, prototype state |
| `lib/motion/` | The named motions (`docs/build/motion.md`) |
| `lib/mock/` | Seed data and the rupiah and date formatters (`docs/build/mock-data.md`) |
| `lib/theme/` | Tokens (`palakat_tokens.dart` is copied from the handoff: never edit or format it), colours and the text theme |
| `tool/` | The registry generator and the screenshot harness (`board_shot.sh`, `app_shot.sh`, `compare.sh`, `dc/support.js`) |
| `assets/fonts/` | Plus Jakarta Sans and IBM Plex Mono as static TTFs, with their SIL OFL licences |

Out of scope, faked as the boards fake it: sign-in, SMS or WhatsApp codes, AI calls, camera, file upload and download, PDF and Excel files, notifications, and persistence across reloads. Nothing leaves the device.
